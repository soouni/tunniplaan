Soovin parandada juba salvestatud tunniplaani

Failist loetakse ainult tunniplaani andmed. Selle koodi ei käivitata.

Kontrolli kõiki viit päeva

    Laadi algne PDF võrdlemiseks alla

    PDF-ist tuuakse üle tunnitabel. Tundide kellaajad ja 2026/2027 koolikalender jäävad seniseks. PDF-i tabelivälised märkused lisa vajadusel ülal.

    Salvestamine laadib faili sinu arvutisse. Kooli veebilehel muutub tunniplaan alles pärast faili asendamist GitHubis. Algne PDF on uue HTML-faili sees; lahtriparandused muudavad veebitabelit, mitte PDF-i.

    Kuidas uuendatud tunniplaan avalikuks teha?
    1. Kontrolli kõik viis päeva ja salvesta uus index.html.
    2. Ava kooli tunniplaani GitHubi hoidla.
    3. Vali Add file → Upload files ja lisa uus fail vana asemele. Faili nimi peab olema täpselt index.html, mitte index (1).html.
    4. Lisa muudatuse kirjeldus ning kinnita Commit changes.
    5. Oota GitHub Pagesi avaldamise lõppu ja kontrolli tunniplaani avalikku lehte.

    Muutmislehe avamine ei anna avaldamisõigust. Avaldamiseks on vaja kooli GitHubi hoidla muutmisõigust.
